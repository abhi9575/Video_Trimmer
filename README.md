# 🚀 Video Trimmer

A fast, modern web application designed to preview, trim, and download video clips effortlessly right in your browser.

---

## ✨ Features

- 🎬 **Video Preview:** Instant visual playback preview for uploaded video files.
- ✂️ **Interactive Trimming:** Easily adjust trim handles along the video timeline to pick exact start and end points.
- 🎨 **Modern Interface:** Built with a clean, dark-mode inspired UI for a slick editing experience.
- ⚡ **Lightning Fast:** Powered by Vite and React for smooth UI interactions and zero latency.
- 📱 **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React (`Play`, `Scissors`, `Download`, `Film`)

---

## 🚀 Getting Started

Follow these steps to get a local copy running on your machine.

### Prerequisites

Make sure you have Node.js installed:
- [Node.js](https://nodejs.org/) (v16.0 or higher recommended)

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/Video-Trimmer.git](https://github.com/your-username/Video-Trimmer.git)

```

2. **Navigate into the project directory:**
```bash
cd Video-Trimmer

```


3. **Install dependencies:**
```bash
npm install

```


4. **Start the development server:**
```bash
npm run dev

```


5. Open your browser and navigate to `http://localhost:5173` to see the application in action!
